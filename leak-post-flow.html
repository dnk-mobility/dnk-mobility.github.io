④표준 작업 순서▾
1
前 공정에서 제품을 갠트리 그리퍼가 피킹하여 리크 지그 기준핀에 맞춰 자동 안착
2
2D 바코드를 자동판독
3
안착된 제품이 내부진입
4
설정된 리크조건으로 검사 채널#0 / 압력 2bar / CHG 15s → BAL1 10s → BAL2 5s → DET 5s / 판정 5ml/min 이하
5
검사가 완료되면 원위치로 복귀
6
갠트리가 제품을 조립후 전체계 리크 테스트 공정으로 이송
7
불량품은 NG 컨베이어로 이송
원본 SOP에는 6단계가 "조립전 전체계"로 오기재되어 있음 — 실제 공정 흐름상 조립후 전체계가 맞아 위와 같이 정정 반영. 원본 문서는 별도 정식 개정 요청 필요.

안전 주의사항

  • 리크 테스트 공정은 고압(1.0bar 이상)의 에어를 제품 내부에 주입하므로, 가동 중 지그 내부나 실링 부위에 절대 손을 대지 말 것
  • 지그 실링 고무 교체 및 갠트리 점검 시 반드시 설비 마스터 전원 차단 및 에어 잔압을 완전히 배기한 후 진입할 것

이상 발생 시 (리크 NG 판정·알람)

  1. 갠트리가 해당 제품을 NG 컨베이어로 정상 배출하는지 확인한다
  2. 배출단 컨베이어 끝에 적재된 NG 제품을 작업자가 수동으로 수거하여 부적합품 격리함에 즉시 투입한다
  3. 수거한 부적합품의 2D 바코드를 확인하여 제품에 누설량 데이터를 기록하고 식별표를 부착한다

부적합품 처리

  1. 즉시 적색마킹 후 부적합 보관장소 보관
  2. 부적합품 처리요령서에 준하여 처리
  3. 작업종료 후 불량 적치대로 이동

⑧트러블슈팅 이력▾
사례 1 — 오링 마모로 인한 간헐적 NG (5/28 야간)
설비 정상

현상: 조립후 유로계 2개, 조립후 하우징 15개 NG 발생. OK 마스터 검사 5회: 0.2~0.3ml/min 정상이었으나, 해당부 오링 마모 발견 → 신규 오링 교체. 불량품 재검사(오링 교체 후) 5개: 1.5~1.8ml/min 정상, 수몰테스트 이상없음.

결론: 오링 마모에 따른 간헐적 마스킹으로 불량품이 발생한 것으로 판단 → 설비 정상, 소모품(오링) 정기 점검 강화 필요

사례 2 — 조립전 OK, 조립후 NG 사례
공정 기인

조립전 유로계 OK(4.1ml/min) → 조립후 유로계 NG(5.48ml/min). 조립전 전체계 하우징 OK(4.09ml/min), 인버터 OK(1.82ml/min) → 조립 후 조립후 전체계 하우징 NG(20.521ml/min), 인버터 OK(0.852ml/min)

결론: 조립 공정(오일니쁠압입·씰캡압입·테이퍼체결·다월핀압입) 중 발생한 결함으로, 조립전/후 검사는 서로 다른 대상(부품 단독 vs 완성 조립체)을 검사하므로 조립전 통과가 조립후 통과를 보장하지 않음
