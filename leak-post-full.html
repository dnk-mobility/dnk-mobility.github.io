④표준 작업 순서▾
1
前 공정에서 제품을 갠트리 그리퍼가 피킹하여 리크 지그 기준핀에 맞춰 자동 안착
2
2D 바코드를 자동판독
3
안착된 제품이 내부진입
4
설정된 리크조건으로 검사 채널#0(하우징): 압력 1bar / CHG 60s → 등압(BAL1) 30s → 평형지연(DL2) 0.5s → 평형(BAL2) 5s → DET 5s / 판정 5ml/min 이하
채널#1(인버터): 압력 1bar / CHG 25s → 등압(BAL1) 5s → 평형지연(DL2) 0.5s → 평형(BAL2) 3s → DET 3s / 판정 5ml/min 이하
5
검사가 완료되면 원위치로 복귀
6
갠트리가 제품을 테이퍼 플러그 돌출높이 검사(공정No.200) 공정으로 이송
7
불량품은 NG 컨베이어로 이송
원본 SOP에는 6단계가 "조립전 전체계"로 오기재되어 있음 — 전체 공정 순서상(190→200) 다음 단계가 돌출높이 검사이므로 위와 같이 정정 반영. 원본 문서는 별도 정식 개정 요청 필요.

안전 주의사항

  • 전체계 리크 테스트는 하우징 내부와 인버터 측 양방향으로 고압의 에어가 주입되므로, 가동 중 설비 작동 구역 내부로 절대 손이나 물체를 넣지 말 것
  • 지그 실링 고무 교체 및 갠트리 점검 시 반드시 설비 마스터 전원 차단 및 에어 잔압을 완전히 배기한 후 진입할 것

이상 발생 시 (리크 NG 판정·알람)

  1. 갠트리가 해당 제품을 NG 컨베이어로 정상 배출하는지 확인한다
  2. 작업자는 NG 컨베이어 끝단에서 제품을 수동 수거하여 부적합품 격리함에 즉시 투입한다
  3. 테스터 모니터에서 어느 채널(하우징 or 인버터)에서 리크가 발생했는지 확인 후, 제품에 기록하고 식별표를 부착한다

부적합품 처리

  1. 즉시 적색마킹 후 부적합 보관장소 보관
  2. 부적합품 처리요령서에 준하여 처리
  3. 작업종료 후 불량 적치대로 이동

⑧트러블슈팅 이력▾
사례 1 — 조립전 OK, 조립후 NG (품질팀 설비 의심 제기 건)
설비 정상

현상: 조립후 유로계·전체계(하우징,인버터) 리크 검사기에서 NG 다수 발생. 품질/소재생산기술팀에서 "조립전 리크검사기에서 걸러졌어야 하지 않냐"며 설비 이상을 제기

OK 마스터 샘플 검사: 하우징 1.79, 인버터 1.3 → 정상. 리크 NG였던 조립완료품을 함침작업 후 재검사: 하우징 1.2~1.3, 인버터 0.9~1.0 → OK로 전환

결론: 설비 이상이 아니며, 함침 처리로 정상화된 것으로 보아 소재 미세 기공(다공성)에 기인한 결함으로 판단. 조립전 유로계 리크 불량(수몰테스트 기포 확인)과 동일한 원인 계열

사례 2 — 특정 로트 대량 NG (5/15 주간, 130건 연계)
소재 결함

조립전 유로부 13개, 조립후 유로부 5개 NG 발생. 5/14 로트 금형수리품에서 리크값 5.64ml/min(기준초과) 확인, 수몰테스트로 실제 리크 재확인 → 로트 소재 결함으로 판단 (조립전 유로계 페이지 사례 2와 동일 건)

공정 이해를 위한 핵심 원칙: 조립전 검사는 부품 단독(가공 직후) 상태를, 조립후 검사는 오일니쁠압입·씰캡압입·테이퍼체결·다월핀압입이 모두 끝난 완성 조립체를 검사합니다. 두 검사는 서로 다른 대상을 측정하므로, 조립전 통과가 조립후 통과를 논리적으로 보장하지 않습니다 (필요충분조건 아님).
