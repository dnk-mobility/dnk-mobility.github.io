표준 작업 순서
  1. 前 공정 제품을 갠트리 그리퍼가 피킹 → 리크 지그 기준핀에 맞춰 자동 안착
  2. 2D 바코드 자동판독
  3. 안착된 제품이 내부진입
  4. 설정된 리크조건으로 검사
    CHG 15s → BAL1 10s → BAL2 5s → DET 5s
  5. 검사 완료 후 원위치 복귀
  6. 갠트리가 제품을 조립전 전체계 리크 테스트 공정으로 이송
  7. 불량품은 NG 컨베이어로 이송

안전 주의사항

  • 고압(1.0bar 이상) 에어 주입 중 지그 내부·실링 부위에 절대 손을 대지 말 것
  • 실링 고무 교체·갠트리 점검 시 반드시 마스터 전원 차단 및 에어 잔압 배기 후 진입

이상 발생 시 (리크 NG 판정·알람)

  • 갠트리의 NG 컨베이어 정상 배출 확인
  • 작업자가 수동 수거 후 부적합품 격리함에 즉시 투입
  • 2D 바코드 확인 → 누설량 데이터 기록 및 식별표 부착

부적합품 처리

  • 즉시 적색마킹 후 부적합 보관장소 보관
  • 부적합품 처리요령서에 준하여 처리
  • 작업종료 후 불량 적치대로 이동
