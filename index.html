안전 주의사항

  • 고압(1.0bar 이상) 에어 주입 중 지그 내부·실링 부위에 절대 손을 대지 말 것
  • 실링 고무 교체·갠트리 점검 시 반드시 마스터 전원 차단 및 에어 잔압 배기 후 진입

이상 발생 시 (리크 NG 판정·알람)

  1. 갠트리의 NG 컨베이어 정상 배출 확인
  2. 작업자가 수동 수거 후 부적합품 격리함에 즉시 투입
  3. 2D 바코드 확인 → 누설량 데이터 기록 및 식별표 부착

부적합품 처리

  1. 즉시 적색마킹 후 부적합 보관장소 보관
  2. 부적합품 처리요령서에 준하여 처리
  3. 작업종료 후 불량 적치대로 이동

  • 전원 On 후 5분 이상 경과 후 계측 시작
  • Settings Lock 해제: 메인메뉴 → 자물쇠 아이콘 → Unlock → 비밀번호 입력(초기값 0000)
  • Remote ↔ Manual 전환: Lock 해제 후 R/M 아이콘 선택
  • 채널 변경: CH# 이동 후 커서 선택 (본 공정은 CH#0 고정)
  • Home 버튼으로 언제든 표준 화면 복귀

사례 1 — 조립전 유로계 리크 불량 다발
설비 정상

수몰테스트에서 기포 확인 → 실제 누설 존재. 설비 이상이 아닌 소재/가공 기인 결함으로 판단.

사례 2 — 특정 로트 NG 다발 (5/15 주간)
설비 정상

유로부 13개 NG. 마스터 시료 0.39 ml/min(정상) 확인. 5/14 로트 금형수리품 5.64 ml/min → 수몰테스트로 리크 재확인. 로트 소재결함으로 판단.
