④표준 작업 순서▾
1
前 공정 제품을 갠트리 그리퍼가 피킹 → 리크 지그 기준핀에 맞춰 자동 안착
2
2D 바코드 자동판독
3
안착된 제품이 내부진입
4
설정된 리크조건으로 검사 CHG 15s → BAL1 10s → BAL2 5s → DET 5s
5
검사 완료 후 원위치 복귀
6
갠트리가 제품을 조립전 전체계 리크 테스트 공정으로 이송
7
불량품은 NG 컨베이어로 이송

안전 주의사항

  • 고압(1.0bar 이상) 에어 주입 중 지그 내부·실링 부위에 절대 손을 대지 말 것
  • 실링 고무 교체·갠트리 점검 시 반드시 마스터 전원 차단 및 에어 잔압 배기 후 진입

이상 발생 시 (리크 NG 판정·알람)

  1. 갠트리의 NG 컨베이어 정상 배출 확인
  2. 작업자가 수동 수거 후 부적합품 격리함에 즉시 투입
  3. 2D 바코드 확인 → 누설량 데이터 기록 및 식별표 부착

부적합품 처리

  1. 즉시 적색마킹 후 부적합 보관장소 보관
  2. 부적합품 처리요령서에 준하여 처리
  3. 작업종료 후 불량 적치대로 이동

⑦조작 매뉴얼 요약 (LS-R700)▾
  • 전원 On 후 5분 이상 경과 후 계측 시작
  • Settings Lock 해제: 메인메뉴 → 자물쇠 아이콘 → Unlock → 비밀번호 입력(초기값 0000)
  • Remote ↔ Manual 전환: Lock 해제 후 R/M 아이콘 선택
  • 채널 변경: CH# 이동 후 커서 선택 (본 공정은 CH#0 고정)
  • Home 버튼으로 언제든 표준 화면 복귀

⑧트러블슈팅 이력▾
사례 1 — 조립전 유로계 리크 불량 다발
설비 정상

수몰테스트에서 기포 확인 → 실제 누설 존재. 설비 이상이 아닌 소재/가공 기인 결함으로 판단.

사례 2 — 특정 로트 NG 다발 (5/15 주간)
설비 정상

유로부 13개 NG. 마스터 시료 0.39 ml/min(정상) 확인. 5/14 로트 금형수리품 5.64 ml/min → 수몰테스트로 리크 재확인. 로트 소재결함으로 판단.

사례 3 — 제품 안착 문제로 리크 결과값 상이 (8/10~8/12)
설비 이상

원인: 제품 안착 문제

조치: 티칭 세팅 수정

사례 4 — 소음기 오일 누수 (5/18)
설비 이상

현상: 소음기에서 오일이 누수되어 바닥·후문에 오일 흔적 발생 (조립전 유로계·전체계 공통)

원인(추정): 부스터 누유 또는 공급 메인 배관 수분 유입

조치: 소음기 제거 후 호스 연결('T'자)로 하부 배출 세팅, 오일팬 제작·설치. 컨버터 누유 여부 확인 후 문제점 조치, 호스는 부위별로 별도 작업 변경

사례 5 — 간헐적 DATA 초기화 (5/18)
설비 이상

현상: HMI 데이터가 간헐적으로 초기화됨 (조립전 유로계·전체계 공통)

원인: HMI가 DnK모빌리티 사급품(노후 제품)

비고: 신규 HMI 구매 필요

참고(6/26): 항온룸 도어 단속이 부실하면 온도가 spec out 되고, 온도 상승이 리크값을 밀어올려 설비 문제로 오판하기 쉽습니다. 리크 NG가 잦아지면 설비 점검 전에 항온룸 온도부터 확인하세요.
